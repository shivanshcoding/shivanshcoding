<h2>🧠 RARE</h2>

<h3>Research-grade Agentic Retrieval Engine</h3>

<p>
A <b>production-grade retrieval framework</b> that uses AI agents to dynamically orchestrate the entire retrieval pipeline—from query understanding and chunking strategy selection to retrieval, reranking, and response generation.
</p>

<p>
Unlike traditional RAG pipelines, <b>RARE intelligently chooses the optimal retrieval strategy at runtime</b>, making retrieval adaptive, modular, and evaluation-driven.
</p>

<h4>✨ Key Features</h4>

<ul>
<li>🧠 Agentic Strategy Planning</li>
<li>🔍 Hybrid Search (Dense + Sparse)</li>
<li>📑 Adaptive Chunking Strategies</li>
<li>🎯 Cross-Encoder Re-ranking</li>
<li>📊 Built-in Retrieval Evaluation</li>
<li>⚡ Plug-and-Play Modular Architecture</li>
</ul>
